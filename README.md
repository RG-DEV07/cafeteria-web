# CafeteríaRG

Sitio web de una cafetería: café preparado al momento, repostería y desayunos. Muestra el lugar, la carta y el horario.

## Tecnologías
- HTML5
- CSS3
- JavaScript (vanilla)

## Estructura
```
index.html        Página principal
css/styles.css    Estilos
js/main.js       Comportamiento de la página
assets/           Recursos (favicon)
```

## Cómo verlo
Abre `index.html` en tu navegador, o visita la versión publicada en GitHub Pages.
